# ADR-0011: Apache-2.0 license

- **Status:** Accepted
- **Date:** 2026-10-28
- **Source:** ARCHITECTURE.md §23

## Context

aipm needs an open-source license that suits individual and enterprise users.

## Options

- MIT.
- Apache-2.0.

## Decision

License aipm under Apache-2.0.

## Consequences

- An explicit patent grant.
- Enterprise-friendly terms.
- Contributions are under the same license.
