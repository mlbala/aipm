### N-2 deny list as implemented

- Exact names (case-sensitive): `PATH`, `HOME`, `TMPDIR`, `NODE_OPTIONS`, `NODE_PATH`, `PYTHONPATH`, `PYTHONSTARTUP`, `PYTHONHOME`, `PERL5OPT`, `PERL5LIB`, `RUBYOPT`, `RUBYLIB`, `JAVA_TOOL_OPTIONS`, `_JAVA_OPTIONS`, `JDK_JAVA_OPTIONS`, `BASH_ENV`, `ENV`, `SHELLOPTS`, `BASHOPTS`, `IFS`, `PS4`, `PROMPT_COMMAND`, `ZDOTDIR`, `GOFLAGS`, `GOPROXY`, `GONOSUMDB`, `GONOSUMCHECK`, `GOINSECURE`, `GOTOOLCHAIN`, `RUSTFLAGS`, `RUSTC_WRAPPER`, `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `COPILOT_HOME`, `GEMINI_CLI_HOME`, `GEMINI_SANDBOX`, `DISABLE_AUTOUPDATER`, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` and `COPILOT_ALLOW_ALL`.

- A test fails if an adapter's config home, or a variable aipm sets for an agent, is missing from the list.

### Checks at the end of session 1

- The full run after the policy commits: ruff, ruff format, pyright, every test (`uv run pytest -q`): 3981 passed, 2 skipped, 2 failed. Both failures were `tests/security/test_layers.py`: the N-5 commit had imported `urllib` in `observability/tracing.py` (`lint-imports` was not run before that commit). The `fix:` commit removes it; `lint-imports` keeps all 7 contracts, and `test_layers.py`, `test_tracing.py`, `test_v04_decisions.py`, `test_no_hidden_characters.py` and the CLI smoke tests pass after it.
- `ci-long` and the 100% branch-coverage run were not repeated; they are for the end of session 2, before the PR.
- Security review of the branch: no critical or high findings. Fixed: the medium (trace host parser mismatch) and three lows (proxy not named, a crash on `~nosuchuser`, a long path hiding its target).
- Re-review of the fix commit: no critical or high findings; a differential fuzz of about 700k endpoints found no host or port mismatch against requests and urllib3. Fixed in a second `fix:` commit: the medium (requests honours any `*_proxy` name in any case, keyed by scheme or `scheme://host`, so every such variable is now named), a regression (`HOME=~user` hid the HOME warning; nothing expands `~` in HOME, so a relative HOME now always warns), an inaccurate docstring about `NO_PROXY`, and a traceback when the exporter cannot be built (an unknown `OTEL_PYTHON_EXPORTER_OTLP_HTTP_CREDENTIAL_PROVIDER`; now a warning, and no spans are sent).

### Open items from the review (not fixed; for the owner)

1. **More `pass_env` names in the classes the owner listed.** The reviewer found names that `denied_pass_env` allows. Go: `GOENV` (an env file can set `GOFLAGS`), `GOSUMDB` (the real checksum switch, unlike `GONOSUMCHECK`, which current Go does not read), `GOPRIVATE`, `GONOPROXY`, `GOWORK`, `GOROOT`, `GOMODCACHE`, `CC`, `CXX`, `CGO_*`. Rust: `RUSTC`, `RUSTC_WORKSPACE_WRAPPER`, `RUSTDOC`, `RUSTDOCFLAGS`, `RUSTUP_TOOLCHAIN`, `RUSTUP_HOME`. Perl and Python: `PERLLIB`, `PERL5DB`, `PYTHONUSERBASE`. Git: `XDG_CONFIG_HOME` (git reads `$XDG_CONFIG_HOME/git/config`). The agents: `SHELL`, `CLAUDE_CODE_SHELL_PREFIX`, `CLAUDE_ENV_FILE`, `GEMINI_CLI_SYSTEM_SETTINGS_PATH`, `GEMINI_CLI_SYSTEM_DEFAULTS_PATH`, `YARN_*`. Low: it needs a user-only key plus a poisoned shell, and the code runs inside the agent's sandbox. The list was the owner's, so nothing was added without asking.
2. **The O-2 refusal does not cover the phase report (`aipm` alone) or `aipm task`.** These commands never load the configuration. `user_redactor` falls back to the built-in patterns for any user config it cannot read, which already happened for one inside the repository. The docs now say "every command that loads the configuration". Making that fatal changes the logging setup that runs before error handling, so it needs a decision.
3. Info: `--no-ignore-pnpmfile` after the allowed prefix still matches. Prepare argv is trusted config, and R-13 covers it.
